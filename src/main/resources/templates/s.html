Single Responsibility Principle

Principio de Responsabilidad Única

Cada clase debe encargarse de una sola cosa.

Si una clase hace demasiadas tareas, será más difícil de modificar y mantener. Lo ideal es que cada clase tenga una única responsabilidad.

Ejemplo: una clase para gestionar usuarios no debería también enviar correos o generar informes.
