Open/Closed Principle

Principio Abierto/Cerrado

Las clases deben estar abiertas para extensión pero cerradas para modificación. El código debe poder ampliarse sin tener que modificar lo que ya funciona.

En lugar de modificar código existente cada vez que aparece un nuevo tipo, se extiende mediante herencia o interfaces.
